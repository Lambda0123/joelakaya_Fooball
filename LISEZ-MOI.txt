V4 - CORRECTION DU HTTP 404

Cette version utilise un NOUVEAU PORT (19877) et une nouvelle route /data.json.
Cela evite les anciennes instances V2/V3 qui pouvaient repondre a la place du programme.

1. Fermer les anciennes fenetres PowerShell du Football Match Tracker.
2. Extraire ce ZIP.
3. Double-cliquer sur Demarrer_Football_Match_Tracker_V4.bat
4. Garder la fenetre PowerShell ouverte.
5. Le navigateur s'ouvre sur la V4.

La V4 recupere jusqu'a 120 jours de calendrier pour les competitions CAF,
UEFA et FIFA, ainsi que plusieurs grands championnats pour les favoris.

Si Windows demande une autorisation pare-feu, autoriser PowerShell sur le reseau prive.
