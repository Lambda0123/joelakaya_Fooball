FOOTBALL MATCH TRACKER V3

Cette version corrige l'erreur HTTP 404 de la V2 en utilisant :
- un nouveau port local : 19876
- une route unique : /football-data
- des sources ESPN par competition
- une plage de calendrier de 120 jours
- plusieurs competitions CAF, UEFA et FIFA

UTILISATION
1. Extraire le ZIP.
2. Double-cliquer sur Demarrer_Football_Tracker_V3.bat.
3. Le navigateur s'ouvre automatiquement.
4. Garder la fenêtre PowerShell ouverte.
5. Cliquer sur Actualiser maintenant.

Si Windows affiche une demande de pare-feu, autoriser l'accès pour PowerShell sur les réseaux privés.

La source ESPN est un endpoint public non officiel : son contenu peut évoluer.
