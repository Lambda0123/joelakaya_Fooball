FOOTBALL MATCH TRACKER
========================

1. Ouvrez "index.html" dans Chrome, Edge ou Firefox.
2. Cliquez sur "Actualiser maintenant".
3. Les données sont récupérées automatiquement depuis des flux publics ESPN lorsque ceux-ci sont disponibles.
4. La liste "Favoris" est modifiable (séparer les noms par des virgules).
5. La page se réactualise automatiquement toutes les 15 minutes.

IMPORTANT
---------
La couverture CAF/CAN dépend du flux public disponible. Pour une version professionnelle couvrant de façon fiable toutes les compétitions, les matchs du Gabon, les résultats en direct et les notifications, il faudra brancher une API football dédiée avec une clé (par exemple football-data.org ou un autre fournisseur). football-data.org documente une API REST pour les calendriers, résultats et compétitions.

Le programme fourni est une première version autonome, sans installation.
