V5 - SOURCE FOOT MERCATO

Cette version utilise le livescore public de Foot Mercato comme source de donnees :
https://www.footmercato.net/live/

UTILISATION
1. Fermer les anciennes versions du programme.
2. Extraire ce ZIP.
3. Double-cliquer sur Demarrer_Football_Match_Tracker_FootMercato_V5.bat
4. Laisser PowerShell ouvert.
5. La page s'ouvre automatiquement.

IMPORTANT
Le site Foot Mercato peut modifier sa structure HTML. Le parseur inclus est donc
une solution pratique mais susceptible de nécessiter une adaptation si le site
change sa présentation. La source reste Foot Mercato et un lien vers leur
livescore est affiché dans l'application.
